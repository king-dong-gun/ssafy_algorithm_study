N개의 자연수가 한 줄로 주어진다.

숫자들이 왼쪽에서 오른쪽으로 이동할수록 계속 작아지는지 확인하려고 한다.

서로 이웃한 두 숫자를 비교했을 때, 앞의 숫자가 뒤의 숫자보다 항상 커야 한다. 즉, 모든 위치에서 다음 조건을 만족해야 한다.

A[i] > A[i+1]

모든 숫자가 이 규칙을 지키며 차례대로 감소한다면 1을 출력하고, 한 번이라도 규칙을 어기면 0을 출력한다.

단, 숫자가 하나만 주어지는 경우에는 비교할 숫자가 없으므로 감소 조건을 만족하는 것으로 한다.



[입력]
첫 번째 줄에 테스트 케이스의 개수 T가 주어진다.

각 테스트 케이스마다 다음과 같이 입력된다.

첫 번째 줄에 자연수의 개수 N이 주어진다.

1 ≤ N ≤ 1000

다음 줄에 N개의 자연수 A1, A2, ..., AN이 공백으로 구분되어 주어진다.

1 ≤ Ai ≤ 10000

[출력]
각 테스트 케이스마다 숫자가 차례대로 감소하면 1, 그렇지 않으면 0을 출력한다.

출력 형식은 다음과 같다.
